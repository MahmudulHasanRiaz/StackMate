- **better-auth 1.7.23 ships the twoFactor plugin** (`better-auth/plugins/two-factor`: `twoFactor`, `twoFactorClient`; endpoints `/two-factor/enable`, `/two-factor/verify-totp`, `/two-factor/verify-backup-code`, `/two-factor/generate-backup-codes`, `/two-factor/disable`, `/two-factor/get-totp-uri`; options `issuer`, `totpOptions {digits, period}`, `backupCodeOptions`, `skipVerificationOnEnable`, `twoFactorCookieMaxAge` default 600s).
