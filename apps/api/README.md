# API application

Reserved for the Hono + TypeScript Cloudflare Worker.

The API owns authentication, authorization, validation, business use cases, and integration adapters. Domain logic must remain independent of Hono and Cloudflare runtime APIs.

Read the TAD, API specification, Security & Threat Model, and Repository Structure document before adding routes or modules. Complete Neon/Drizzle and Better Auth compatibility spikes before selecting production connection/session behavior.
